# Print Cleaner for VRChat（Chrome拡張機能）

VRChatのプリントが上限（初期設定 64 枚）に達したら、★で保護していないものを古い順に自動削除します。

- 認証情報（ID・パスワード・トークン）は保存しません。vrchat.com にログイン済みのブラウザのCookieをそのまま使います。
- 通信先は VRChat の API（`api.vrchat.cloud` / `vrchat.com`）と、画像の配信先（`*.vrchat.cloud`、`assets.vrchat.com`）だけです。外部サーバーへの送信はありません。
- 非公式ツールです。VRChat公式のサポート対象外で、APIの仕様変更により動かなくなる可能性があります。

## インストール

1. zip を展開する
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパー モード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」で展開したフォルダを選ぶ
5. 同じChromeで https://vrchat.com にログインしておく

## 使い方

1. 拡張機能アイコン →「一覧・設定」を開く
2. 残したいプリントの ☆ をクリックして ★ にする（保護）
3. 最初は「ドライラン」をオンにして「自動削除」を有効化し、ログで削除対象が想定どおりか確認する
4. 問題なければドライランをオフにする

アイコンのバッジに現在の枚数が出ます（青＝余裕あり、赤＝上限、灰＝自動削除OFF、橙の「!」＝エラー）。

## 動作の仕組み

- 指定した間隔（初期設定 1 分）ごとに `GET /auth/user` → `GET /prints/user/{userId}` で枚数を確認
- 「削除開始の枚数」以上なら、保護されていないプリントを作成日時の古い順に「削除後の枚数」まで `DELETE https://api.vrchat.cloud/api/1/prints/{printId}`
- 1回あたりの削除数には上限あり（初期設定 5 枚）。削除リクエストの間は 1.5 秒空ける
- 「削除前に画像を保存」がオンなら、許可したフォルダの `VRChatPrints/` へ直接保存し、保存できたものだけを削除する。ファイルごとの保存ダイアログは出さない。Chrome はタブやブラウザを閉じるとフォルダ許可を一度捨てるので、そのあと一覧で「保存先へのアクセスを再開」を押し、「次回以降も許可」を選ぶと再許可は不要になる
- APIは vrchat.com のページから呼びます。拡張機能自身のオリジンは VRChat に拒否されるためです。タブが無いときは背面で vrchat.com を1つ開きます

## 設定

| 項目 | 初期値 | 説明 |
|---|---|---|
| 自動削除 | OFF | 初回の有効化時に確認ダイアログを表示 |
| ドライラン | OFF | 削除せず、削除対象をログに記録するだけ |
| 削除開始の枚数 | 64 | VRC+ 未加入なら 20 |
| 削除後の枚数 | 63 | 連続撮影に備えるなら 60 など |
| チェック間隔 | 1 分 | 1〜60 分 |
| 1回の最大削除数 | 5 | 誤作動したときの被害を抑えるための上限 |
| 削除前に画像を保存 | ON | 許可したフォルダへ直接保存。切れたら「次回以降も許可」で再開する。失敗したプリントは削除しない |
| 他人のプリントは削除しない | OFF | ONにすると、他の人から受け取ったプリントを削除対象から外す |

★の保護リストと設定は `chrome.storage.sync` に保存されるため、同じGoogleアカウントでログインしたChrome間で共有されます。

## 注意

- Chromeが起動していないときは動きません（バックグラウンドで起動したままにしておく必要があります）
- 「削除後の枚数」が 63 だと、短い間に連続でプリントを撮ったときにチェックが間に合わず、上限に達することがあります
- VRChat上で削除したプリントは元に戻せません
